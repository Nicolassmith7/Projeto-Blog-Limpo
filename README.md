O Blog Limpo é um projeto web desenvolvido por mim com o objetivo de compartilhar curiosidades, descobertas e informações fascinantes sobre o universo. Criado com HTML5, CSS3 e JavaScript, o blog oferece uma experiência de navegação leve, responsiva e visualmente atrativa.

Com um design inspirado na estética espacial, o blog traz artigos sobre planetas, estrelas, galáxias, buracos negros, missões espaciais e tudo que envolve o cosmos — ideal para entusiastas e curiosos do tema.

🔧 Tecnologias utilizadas:
HTML5 – Estrutura semântica

CSS3 – Estilização com foco visual astronômico

JavaScript – Interatividade e dinamismo

🌠 Funcionalidades:
Layout responsivo

Menu interativo

Seções organizadas por temas (ex: sistema solar, curiosidades, notícias)

Design voltado à imersão no tema espacial

Esse projeto faz parte do meu portfólio e representa minha evolução no desenvolvimento front-end, combinando programação com uma paixão pessoal pela astronomia.
